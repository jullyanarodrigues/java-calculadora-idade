# 💻 Calculadora de Idade em Java

Projeto desenvolvido durante meus estudos de Java com o Gustavo Guanabara (Curso em Vídeo) 💛

---

## ✨ Sobre o projeto

Uma aplicação simples com interface gráfica (Swing) que calcula a idade com base no ano de nascimento.

Além da lógica, explorei também a parte visual, deixando a experiência mais amigável e interativa (com direito a cursor personalizado 😄).

---

## 🧠 O que eu pratiquei

- Uso de `JSpinner` para entrada de dados  
- Captura de valores com `getValue()`  
- Conversão de dados com `Integer.parseInt()`  
- Uso de `LocalDate.now().getYear()` para obter o ano atual  
- Operador ternário para tratar singular/plural ("ano"/"anos")  
- Personalização da interface (imagem em JLabel e cursor interativo)  

---

## 🎯 Funcionalidades

- Cálculo automático da idade  
- Exibição do ano atual  
- Tratamento de singular/plural na idade
